# LegendMine — Официальный сайт сервера Minecraft

🌐 **Сайт онлайн:** [https://boxingharmoni.github.io/legendmine/](https://boxingharmoni.github.io/legendmine/)

---

## 📌 О проекте

**LegendMine** — легендарный игровой Minecraft-сервер (версии 1.8 — 1.21, Java & Bedrock).
Данный репозиторий содержит полноценный фронтенд сайта сервера:
- **Главная страница (`index.html`)**: мониторинг онлайна, копирование IP (`legendmine.ru`), список режимов (Анархия, Гриферское выживание, SkyBlock, Duels), преимущества, последние новости и статистика.
- **Магазин привилегий и доната (`donate.html`)**: удобная витрина привилегий (VIP, Premium, Holy, Legend, Владелец) и игровых кейсов.
- **Личный кабинет игрока (`profile.html` / `profile.js`)**: статистика игрока, баланс монет, скины, настройки безопасности и привязка аккаунтов.
- **Адаптивный дизайн**: плавная анимация частиц, неоновые эффекты, поддержка мобильных устройств.

## 🚀 Запуск локально
Просто откройте `index.html` в любом современном браузере.
