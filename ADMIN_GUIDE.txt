2. ВРЕМЕННЫЕ ДЕМО-АККАУНТЫ (КАК ОТКЛЮЧИТЬ / НАСТРОИТЬ)
--------------------------------------------------------------------------------
Для наглядности на странице профиля (profile.html) сейчас отображается блок
"Временные демо-аккаунты для теста".

В файле `profile.js` в самом верху находится блок конфигурации:

    const CONFIG = {
      // Показывать ли блок временных демо-аккаунтов на форме входа:
      ENABLE_DEMO_ACCOUNTS: true,

      // Пароль для доступа к консоли администратора:
      ADMIN_CONSOLE_PASSWORD: 'legendmine_admin',
    };

КАК ОТКЛЮЧИТЬ ДЕМО-АККАУНТЫ:
Когда вы подключите сайт к базе данных сервера (AuthMe / MySQL), просто измените:
    ENABLE_DEMO_ACCOUNTS: false
После этого кнопки демо-аккаунтов исчезнут, и пользователи смогут входить
только через свои настоящие логины и пароли.

3. ВКЛАДКА "КОНСОЛЬ" ДЛЯ АДМИНИСТРАЦИИ
--------------------------------------------------------------------------------
Вкладка "Консоль" предназначена ТОЛЬКО для администратора сервера.

ПРИНЦИП РАБОТЫ И ЗАЩИТА:
1. Обычные игроки НЕ видят кнопку вкладки "Консоль" (она скрыта в коде display:none).
   Даже если игрок попытается принудительно кликнуть по ней через консоль браузера,
   скрипт проверяет флаг `isAdmin === true` у текущего авторизованного игрока.
   Не-админы получают уведомление: "Доступ запрещён: вкладка только для Администратора!".
2. При открытии вкладки "Консоль" срабатывает второй уровень защиты — шлюз с паролем.
   Пароль по умолчанию:
       legendmine_admin
3. КАК СМЕНИТЬ ПАРОЛЬ КОНСОЛИ:
   В файле `profile.js` измените значение:
       ADMIN_CONSOLE_PASSWORD: 'ваш_новый_сложный_пароль'
4. КАК ВЫДАТЬ ИГРОКУ СТАТУС АДМИНИСТРАТОРА:
   В объекте игрока в `profile.js` (или в вашей базе данных) укажите:
       isAdmin: true

ВОЗМОЖНОСТИ АДМИН-КОНСОЛИ:
- Список всех игроков с поиском по нику и статусом онлайн/оффлайн.
- Просмотр ПОЛНОГО профиля любого выбранного игрока:
  * 3D скин и ранг игрока
  * Kills / Deaths / K/D / Баланс / Время в игре / IP-адрес
  * Полный инвентарь и снаряжение игрока с текстурами и зачарованиями
- Кнопки быстрого наказания/действия: Кик, Бан, Мут, TP.
- Интерактивный терминал с логами и вводом команд:
  * list / players — список игроков онлайн
  * kick <ник>     — кикнуть игрока
  * ban <ник>      — забанить игрока
  * mute <ник>     — замутить игрока
  * tp <ник>       — телепортироваться к игроку
  * give <ник>     — выдать предмет
  * op <ник>       — выдать права оператора
  * clear          — очистить окно консоли
  * online / tps / uptime — статистика работы
- Панель мониторинга сервера (TPS, RAM, CPU, время непрерывной работы).

5. ИНТЕГРАЦИЯ С РЕАЛЬНЫМ СЕРВЕРОМ MINECRAFT
--------------------------------------------------------------------------------
Чтобы сайт стал живым и брал реальные данные с сервера:

1. АВТОРИЗАЦИЯ ИГРОКОВ:
   - Если на сервере установлен плагин AuthMe Reloaded:
     В конфигурации AuthMe `config.yml` включите хранение в MySQL:
         DataSource:
           backend: 'MYSQL'
           mySQLHost: 'localhost'
           mySQLPort: '3306'
           mySQLDatabase: 'minecraft'
           mySQLUsername: 'mc_user'
           mySQLPassword: 'password'
     Создайте простой бэкенд (PHP или Node.js), который принимает логин/пароль с сайта
     и проверяет хеш пароля SHA256 / BCrypt из таблицы `authme`.

2. ИНВЕНТАРЬ И РЕСУРСЫ:
   - Вариант А: Плагин "MySQLPlayerDataBridge" или "InventoryRollbackPlus"
     сохраняет инвентарь игрока в базу данных MySQL. Бэкенд считывает предметы
     и передаёт на сайт в формате JSON:
     `{ id: 'diamond_sword', count: 1, enchants: ['Острота V', 'Огонь II'] }`.
   - Вариант Б: Плагин "WebStats" или "Plan" (Player Analytics)
     предоставляет готовый REST API для получения статов, инвентаря и онлайна.

3. БАЛАНС И ВАЛЮТА:
   - Баланс считывается из таблицы экономики плагина EssentialsX / CMI / Vault (MySQL).

4. ВЫПОЛНЕНИЕ КОМАНД ИЗ КОНСОЛИ НА СЕРВЕРЕ (RCON):
   - В файле сервера `server.properties` включите RCON:
         enable-rcon=true
         rcon.port=25575
         rcon.password=ваш_rcon_пароль
   - Ваш бэкенд пересылает введённую в админ-консоли команду прямо на сервер
     через RCON-клиент и возвращает ответ в окно терминала на сайте.

5. ОНЛАЙН СЕРВЕРА:
   - Реальный онлайн на главной странице можно получать через бесплатный API:
     https://api.mcsrvstat.us/2/legendmine.ru
     (в script.js достаточно сделать fetch на этот адрес).

6. ПОДКЛЮЧЕНИЕ ДОНАТА И ПЛАТЁЖНЫХ СИСТЕМ
--------------------------------------------------------------------------------
В файле `donate.html` представлены все популярные способы оплаты (Карта, ЮMoney, СБП).
Для приема реальных платежей:
1. Зарегистрируйтесь в агрегаторе платежей (AnyPay, FreeKassa, Unitpay, Enot, Lava или ЮKassa).
2. Настройте обработчик оповещений (Webhook / Result URL).
3. При успешной оплате платёжная система обращается к вашему сайту, а скрипт
   выполняет команду выдачи доната через RCON:
       lp user {NICK} parent set {RANK}
       broadcast &6Игрок &e{NICK} &6приобрёл привилегию &a{RANK}!


--------------------------------------------------------------------------------
7. РАЗВЁРТЫВАНИЕ САЙТА НА ХОСТИНГЕ / VDS
--------------------------------------------------------------------------------
Сайт полностью автономен и не требует сборщиков (чистый HTML5, CSS3, ES6 JavaScript).
- Для Nginx / Apache:
  Просто скопируйте все файлы из этой папки в директорию веб-сервера:
  `/var/www/html/` (или корень вашего домена).
- Для локальной проверки:
  Запустите команду в терминале:
      python -m http.server 8080
  и откройте в браузере: http://localhost:8080/
