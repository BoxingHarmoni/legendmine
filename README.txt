LEGENDMINE MINECRAFT SERVER WEBSITE
====================================
Подробная инструкция для администратора находится в файле:
--> ИНСТРУКЦИЯ_АДМИНИСТРАТОРУ.txt

Быстрый старт:
- Главная страница: index.html
- Личный кабинет: profile.html
- Магазин доната: donate.html

Конфигурация в profile.js:
- ENABLE_DEMO_ACCOUNTS: true/false (скрыть или показать временные демо-аккаунты)
- ADMIN_CONSOLE_PASSWORD: 'legendmine_admin' (пароль к консоли администратора)

Вход в админ-консоль:
- Войдите под аккаунтом DiamondKing_ (пароль: king456)
- Откройте вкладку "Консоль"
- Введите пароль: legendmine_admin
Обычные игроки (например BoxingHarmony) вкладку "Консоль" не видят и не имеют к ней доступа.
